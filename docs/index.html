GhostLang

Linguagem compilada (transpilada para C++17) com computação quântica, IA e deep learning, álgebra hipercomplexa G e um servidor HTTP e WebSocket nativos. Em desenvolvimento: Windows x64 testado; Linux e macOS são as próximas etapas.
