A Filosofia do GhostLang

"Por que criar uma nova linguagem de programação em um mundo saturado de opções? Porque a computação clássica, a computação quântica e a inteligência artificial não podem mais viver em mundos isolados."

Durante décadas, a ciência da computação operou sob uma clara divisão de trabalho. O desenvolvimento de sistemas de alta performance pertencia ao C e C++; a análise de dados e prototipagem de redes neurais pertencia ao Python; e os simuladores de computação quântica eram mantidos como bibliotecas externas complexas, difíceis de instalar e desacopladas dos compiladores nativos.

O GhostLang nasceu com a missão ousada de romper essas barreiras. Criada do zero com foco em três pilares inegociáveis:

  • Desempenho Nativo Extremo: Programas GhostLang são analisados em uma Árvore Sintática Abstrata (AST) rigorosa e transpilados diretamente para código C++17 ultra-otimizado com suporte a OpenMP e CUDA, gerando binários estáticos sem qualquer dependência de máquinas virtuais lentas ou interpretadores pesados.
  • Computação Quântica como Cidadã de Primeira Classe: Qubits, registradores quânticos (qreg), circuitos variacionais (circuit), matrizes de densidade e medições probabilísticas não são pacotes de terceiros. Eles fazem parte da própria gramática e do runtime C++ do GhostLang.
  • Inteligência Artificial e Álgebra Hiper-Complexa Nativas: O operador de pipeline de camadas neurais >>, diferenciação automática reversa (Autograd), números 4D de álgebra fantasma G, e tensores N-dimensionais estão embutidos no coração da linguagem.

Capítulo 1

Introdução, Instalação e Arquitetura da Toolchain

Compreenda a anatomia do GhostLang: como o compilador transforma código-fonte de alto nível em binários nativos C++17 ultra-otimizados com suporte a OpenMP e CUDA.

1.1 Como o GhostLang Funciona

Diferente de linguagens interpretadas tradicionais que dependem de uma máquina virtual pesada (como JVM ou CPython), o GhostLang opera sob um modelo de transpilação de alta fidelidade para C++17 ISO.

Pipeline de Compilação do GhostLang Fluxo Arquitetural 
Código Fonte (.g) 
  ↓ [Lexer (Tokenização & Comentários)]
Fluxo de Tokens
  ↓ [Parser & GhostAst (Construção da Árvore Sintática Abstrata)]
AST Unificada
  ↓ [GhostTypes (Verificação Semântica Estrita - 102 Regras)]
AST Validada & Tipada
  ↓ [GhostCodegen (Emissão de C++17 + Runtime Nativo)]
Código C++17 Otimizado (com #include <GhostMatrix.hpp>, <GhostQuantum.hpp>)
  ↓ [g++ (-O3 -fopenmp; -static por padrão no Windows)]
Binário Executável Nativo Autônomo (.exe / ELF)

1.2 Instalação e Estrutura de Diretórios

No Windows, a forma mais simples é o pacote portátil GhostLang-Portable-x64.zip. Ele traz o compilador C++ (GCC 16.2 em bin/compiler), o depurador (gdb em bin/gdb), o runtime com OpenBLAS, as bibliotecas .g, exemplos e a documentação. Não é preciso instalar o MSYS2 nem mexer no PATH do sistema:

  1. Descompacte o zip e confira o SHA-256 em GhostLang-Portable-x64.sha256.
  2. Para usar sem instalar, abra iniciar_prompt.bat. Para instalar, rode instalar.bat: ele copia para %LOCALAPPDATA%\Programs\GhostLang, põe o ghost no PATH do usuário (sem administrador) e cria um atalho no Menu Iniciar. desinstalar.ps1, na pasta instalada, desfaz tudo.
  3. ghost run examples\ola_mundo.g compila e executa; ghost sozinho abre o REPL.

Também dá para compilar a partir do código com CMake e Ninja (cmake -S . -B build e ninja -C build). Linux e macOS ainda não têm pacote. No código-fonte, a organização é:

Diretório Finalidade
bin/ Binários executáveis principais (ghost.exe, ghost_api, ghost_ask).
include/ Cabeçalhos C++ do runtime (GhostQuantum.hpp, GhostMatrix.hpp, GhostHybrid.hpp).
libs/ Biblioteca padrão em GhostLang (fs.g, http.g, json.g, time.g, tensor.g, quantum.g, gui.g...).
tests/ Suíte de testes de regressão (203 testes CTest: goldens do compilador, paridade com o REPL, oráculo do C++ gerado, CLI, pacote e instalador).
examples/ e scripts/ Exemplos (cada um passa no ghost check no CTest) e scripts de empacotamento, instalador, OpenBLAS e gdb.
dashboard/ Painel de métricas e status oficial da linguagem (ghostlang-status.json).

2.2 Números Complexos Nativos

Em muitas linguagens, números complexos exigem a importação de bibliotecas lentas. No GhostLang, o número imaginário i é um literal nativo do Lexer. Você pode somar, subtrair, multiplicar e dividir números complexos diretamente:

exemplos/complexos.g GhostLang Source 
function void main() {
    complex z1 = 1.0 + 2.0i;
    complex z2 = 3.0 - 1.0i;
    
    complex soma = z1 + z2;       // 4.0 + 1.0i
    complex produto = z1 * z2;    // (1*3 - 2*(-1)) + (1*(-1) + 2*3)i = 5.0 + 5.0i
    
    println(f"z1 = {z1}");
    println(f"z2 = {z2}");
    println(f"z1 + z2 = {soma}");
    println(f"z1 * z2 = {produto}");
}

2.3 Interpolação de Texto (f-strings)

O GhostLang oferece interpolação de strings de alta performance em tempo de compilação com a sintaxe f"...". As expressões dentro das chaves {expressao} são avaliadas e convertidas diretamente para string sem alocações desnecessárias. Para imprimir uma chave literal, basta duplicá-la: {{ ou }}.

exemplos/fstrings.gGhostLang Source
function void main() {
    float raio = 5.0;
    float area = 3.14159 * raio * raio;
    println(f"Circulo de raio {raio} tem area = {area} m2.");
    println(f"JSON simulado: {{\"raio\": {raio}, \"area\": {area}}}");
}

2.4 Entrada de Dados Interativa: input e inputln

Para interagir com o usuário via terminal ou capturar parâmetros em tempo de execução, o GhostLang oferece suporte nativo e de alta performance à leitura de dados pelo console com descarte automático de quebras de linha residuais:

2.4.1 Atribuição Direta com Retorno Tipado (input)

A função input(prompt) opera como uma expressão com retorno dinamicamente conversível, atribuindo o texto digitado diretamente ao tipo estático da variável (string, int, float, double ou bool):

function void main() {

A instrução de comando inputln(f"Prompt: {variavel}") permite projetar o prompt e vincular a variável receptora diretamente dentro das chaves {variavel} da f-string:

2.6 Operações Matemáticas Clássicas e Avançadas (libs/math.g)

O GhostLang possui suporte nativo integral à matemática analítica, clássica e computacional de alta precisão. A linguagem integra operadores de ponta diretamente na sintaxe do compilador, além de fornecer a biblioteca especialista libs/math.g.

2.6.1 Exponenciação e Potenciação (x^n)

A exponenciação (xn, lê-se "x elevado a n") utiliza o operador universal **, possuindo alta precedência e associatividade da direita para a esquerda:

exemplos/potencia.gGhostLang Source
function void main() {
    int base_int = 2;
    int exp_int = 10;
    int resultado = base_int ** exp_int; // 2^10 = 1024 (inteiro exato)
    double fracao = 4.0 ** -0.5;        // 4^(-0.5) = 0.5 (flutuante)
    println(f"2 elevado a 10 = {resultado}");
    println(f"4 elevado a -0.5 = {fracao}");
}

2.6.2 Raiz Quadrada e Raiz n-ésima Universal (n√x)

Para o cálculo de raízes, o GhostLang oferece tanto as funções elementares sqrt(x) (raiz quadrada, idêntica ao padrão de C++) e cbrt(x) (raiz cúbica), quanto a função universal para raiz n-ésima raiz_n(x, n) (também disponível como nth_root(x, n)).

Onde o índice da raiz n pode ser qualquer número natural maior do que zero (n ≥ 1):

  • Radicando positivo (x ≥ 0): calcula n√x = x1/n com rigor IEEE 754 em precisão dupla (double).
  • Radicando negativo (x < 0) com índice ímpar: calcula a raiz real exata no corpo dos reais: 3√(-8) = -2, 5√(-32) = -2.
  • Raiz de números negativos e corpo dos Complexos (complex): Como o GhostLang possui suporte nativo ao tipo complex, é plenamente possível calcular raízes de números negativos e raízes de índice par! O GhostLang disponibiliza as funções especializadas csqrt(z) (raiz quadrada complexa) e raiz_n_complexa(z, n) (ou nth_root_c(z, n) / sobrecarga raiz_n(complex z, n)). Ao passar um número negativo, o cálculo opera no corpo dos complexos retornando o ramo principal:
    • √(-4) = 2i → (0, 2)
    • √(-1) = 1i → (0, 1)
    • √(-16) = 4i → (0, 4)
    • 4√(-16) = √2 + √2·i → (1.41421, 1.41421)
    • Raízes de números complexos arbitrários: sqrt(3.0 + 4.0i) → (2, 1) (2 + 1i).
  • Validação estrita de domínio: caso n ≤ 0, lança erro informando que o índice deve ser um número natural maior do que zero (n ≥ 1). No domínio estritamente real (raiz_n(double, int) com índice par e radicando negativo), orienta o desenvolvedor a utilizar o tipo nativo complex.
exemplos/raizes.gGhostLang Source
import "libs/math.g";

function void main() {
    // 1. Raizes no dominio real
    double raiz2 = sqrt(144.0);             // Raiz quadrada: 12.0
    double raiz3 = cbrt(125.0);             // Raiz cubica: 5.0
    double raiz10 = raiz_n(1024.0, 10);      // Raiz decima de 1024: 2.0
    double raiz5_neg = nth_root(-32.0, 5);   // Raiz quinta de -32: -2.0
    println(f"Raiz decima de 1024 = {raiz10}");
    println(f"Raiz quinta de -32 = {raiz5_neg}");

    // 2. Raizes de numeros negativos com complex nativo
    complex raiz_neg4 = csqrt(-4.0);         // Raiz quadrada de -4: 2i -> (0, 2)
    complex raiz_neg1 = csqrt(-1.0);         // Raiz quadrada de -1: 1i -> (0, 1)
    complex raiz_cplx = sqrt(3.0 + 4.0i);    // Raiz de complexo -> (2, 1)
    complex raiz4_neg16 = raiz_n_complexa(-16.0, 4); // Raiz 4a de -16: (1.41421, 1.41421)
    complex raiz2_neg9 = raiz_n(-9.0 + 0.0i, 2);     // Sobrecarga complexa -> (0, 3)
    println(f"csqrt(-4.0) = {raiz_neg4}");
    println(f"csqrt(-1.0) = {raiz_neg1}");
    println(f"raiz_n_complexa(-16, 4) = {raiz4_neg16}");
    println(f"raiz_n(-9+0i, 2) = {raiz2_neg9}");
}

Para iterações com contador ou condição, usamos o for clássico e o while. Operações que possam falhar (como divisão por zero, leitura de arquivos inexistentes ou índices fora do limite) devem ser protegidas com blocos estruturados de exceção. O bloco finally é sempre executado, garantindo liberação de recursos mesmo em caso de erro:

exemplos/erros.gGhostLang Source
function float dividir_seguro(float a, float b) {
    try {
        if (b == 0.0) {
            throw "Erro de Divisão: Denominador não pode ser nulo!";
        }
        return a / b;
    } catch (string erro) {
        println(f"Interceptado: {erro}");
        return 0.0;

        println("Operação aritmética finalizada.");
    }
}

Funções de Primeira Classe, Lambdas e Concorrência

4.1 Funções de Primeira Classe e Expressões Lambda

Em GhostLang, funções são tratadas como cidadãs de primeira classe: podem ser passadas como argumentos, retornadas por outras funções ou armazenadas em variáveis. As expressões lambda possuem sintaxe dual, oferecendo máxima expressividade:

  • Notação Matemática com Pipes (padrão moderno): |parametros| => expressao (para zero parâmetros: || => expressao).
  • Notação Clássica com Parênteses: (parametros) => expressao (para zero parâmetros: () => expressao).

Os parâmetros suportam tanto tipagem estática explícita (como |int x|) quanto inferência automática polimórfica (como |x|). As coleções list<T> expõem métodos funcionais nativos de ordem superior (map, filter, reduce e for_each):

exemplos/lambdas.gGhostLang Source
function void main() {
    // 1. Lambdas atribuídas a variáveis (tipada e inferida)
    var dobrar = |int x| => x * 2;
    var quadrado = |x| => x * x;
    println(f"O dobro de 7 e: {dobrar(7)}");
    println(f"O quadrado de 9 e: {quadrado(9)}");

    // 2. Pipeline funcional sobre coleções
    list<int> valores = [1, 2, 3, 4, 5, 6];
    list<int> pares = valores.filter(|x| => x % 2 == 0);
    list<int> valoresDobrados = pares.map(|x| => x * 2);
    
    println(f"Numeros pares: {pares}");
    println(f"Valores dobrados: {valoresDobrados}");
}

4.2 Concorrência Real com Threads e Mutex

Ao contrário de interpretadores que possuem travas globais (GIL), o GhostLang compila cada bloco spawn { } para uma thread real do sistema operacional (std::thread no C++ gerado). mutex, lock e unlock protegem os dados compartilhados. Como spawn não devolve um objeto para join, o programa espera com sleep(ms):

exemplos/threads_mutex.gGhostLang Source
int contador_global = 0;

function void main() {
    mutex trava_memoria;
    for (int t = 1; t <= 2; t++) {
        spawn {
            for (int i = 0; i < 5000; i++) {
                lock(trava_memoria);
                contador_global = contador_global + 1;
                unlock(trava_memoria);
            }
        }
    }
    sleep(500);   // spawn não tem join: o main espera as threads terminarem
    lock(trava_memoria);
    println(f"Valor final sincronizado: {contador_global} (esperado: 10000)");
    unlock(trava_memoria);
}

5.3 Acesso aos Membros: public, protected e private

O acesso aos membros é conferido de verdade, no compilador e no REPL. O modificador pode abrir uma seção (private:) ou vir junto do membro (private double saldo;):

  • public (o padrão): qualquer código acessa.
  • protected: a própria classe e as classes que herdam dela.
  • private: só a própria classe.

Ler, escrever ou chamar um membro proibido dá o erro GHOST-E0303 com linha e coluna, antes de gerar o C++. No REPL, o mesmo acesso dá [Erro] na hora.

class Conta {
    private double saldo;
    protected string dono;
    public int numero;

    function Conta(string d, int n) { this.dono = d; this.numero = n; this.saldo = 0; }
    private function bool valido(double v) { return v > 0; }
    function void depositar(double v) { if (valido(v)) { saldo += v; } }
    function double ver() { return saldo; }
}

    protected double taxa;
    function Poupanca(string d, int n, double t) { super(d, n); this.taxa = t; }

    function string descricao() { return "Poupanca de " + dono; } // protected: a filha enxerga
}

    p.depositar(40);
    p.render();

    p.numero = 20;                                  // public: pode
    // p.saldo = 1;    erro GHOST-E0303: 'saldo' e private na classe Conta

Capítulo 6

Álgebra Hiper-Complexa G (4D) e Tensores N-Dimensionais

Aprofunde-se na assinatura matemática única do GhostLang: os Números Fantasmas 4D, comutadores quânticos, propagação analítica de incerteza, tensores multidimensionais e aceleração via GhostBLAS.

6.1 Os Números Fantasmas G: Definição e Estrutura 4D

O GhostLang introduz como primitivo matemático o número hiper-complexo Fantasma G, modelado em quatro coordenadas ortogonais:

G = x + y·i + p·g + θ²

Onde:

  • x (Parte Real): Representa grandezas físicas clássicas e escalares.
  • y (Parte Imaginária i): Comportamento oscilatório e amplitudes de fase (i² = -1).
  • p (Parte Fantasma g): Componente diferencial de incerteza quântica ou gradiente propagado.
  • θ (Incerteza Grassmanniana / Dual): Elemento nilpotente onde θ² = 0, utilizado em derivadas automáticas e aproximações de perturbação.
⚠️ Nota Matemática Rigorosa sobre a Álgebra G
Conforme verificado em src/GhostNumberG.cpp, o produto dos números G não é estritamente associativo em todas as combinações: para o fantasma puro θ = (0, 0, 1), temos (i · i) · θ = -θ, enquanto i · (i · θ) = 0. Esta propriedade é intencional e reflete a física de comutadores e anti-comutadores de campos fermiônicos e estados entrelaçados.

6.2 Criando e Manipulando Números G no Código

No GhostLang, o tipo ghost é de primeira classe e pode ser criado com literais (como 1.0 + 2.0i + 3.0g) ou diretamente através do construtor explícito ghost(x, y, p, theta2):

    println(f"g1 em 4D: {g1:4d}");
    println("g1 em 4D com to_4d(): " + g1.to_4d());

6.2.1 Formatos de Saída em print e println

O GhostLang oferece suporte nativo e flexível para exibir números fantasmas tanto na forma vetorial 4D quanto na forma algébrica matemática clássica:

  • Formato Padrão: (x, yi, p, θ²) = (3.0000, 4.0000, 1.7000, 2.0000) — representação canônica rigorosa com 4 casas decimais.
  • Formato 4D Vetorial: G = (3.0, 4.0, 1.7, 2.0) — exibe as 4 coordenadas (x, yi, p, θ²). Acessível via especificador de f-string {g:4d} ou pelo método g.to_4d().

6.3 Matrizes e Álgebra Linear de Alta Performance: matrix e GhostMatrix

O GhostLang oferece uma arquitetura matricial de alto desempenho com suporte a duas abordagens complementares e interoperáveis: o tipo conciso matrix para álgebra linear numérica clássica e a classe estendida GhostMatrix para computação hipercomplexa 4D e inteligência artificial quântica. Ambas contam com aceleração paralela multi-thread nativa via OpenMP e kernels dedicados em GPU (CUDA).

6.3.1 Álgebra Linear Numérica com matrix

O recurso matrix foi projetado para operações matemáticas rigorosas, resolução de sistemas lineares, decomposições e computação científica:

  • Instanciação Direta: matrix A(linhas, colunas); aloca a matriz com inicialização segura de zeros.
  • Manipulação de Células: A.set(i, j, valor) define o elemento na posição especificada e A.get(i, j) recupera seu valor, com verificação estrita de limites de dimensionalidade.
  • Inversão Numérica Rigorosa (Gauss-Jordan): O método A.inverse() (ou seu alias A.inv()) calcula a matriz inversa A⁻¹ com pivotamento parcial, detectando matrizes singulares com precisão de máquina.
  • Cálculo de Determinante: A.determinant() (ou A.det()) computa \det(A) em tempo cúbico O(n³).
  • Aritmética e Multiplicação: Suporte nativo aos operadores A * B (produto matricial acelerado por hardware), A + B, A - B, além de multiplicação e divisão por escalares (A * 2.0, A / 2.0).
  • Exibição Tabular Formatada: A.show() imprime a matriz com alinhamento tabular e colchetes limpos. Interpolações diretas em f-strings como println(f"{A}") ou println(A) também são aceitas diretamente.
exemplos/matrizes.gGhostLang Source
// Álgebra Linear Clássica e Resolução de Sistemas: matrix
function void main() {
    // 1. Instanciação de uma matriz 2x2
    matrix A(2, 2);
    A.set(0, 0, 4.0); A.set(0, 1, 7.0);
    A.set(1, 0, 2.0); A.set(1, 1, 6.0);

    // 2. Inversão matricial exata via Gauss-Jordan
    matrix A_inv = A.inverse();
    matrix I = A * A_inv; // Matriz Identidade Resultante (I) = A * A_inv

    println("Matriz A original:");
    A.show();
    println("Matriz A inversa A^-1:");
    A_inv.show();
    println("Matriz Identidade Resultante (I) = A * A^-1:");
    I.show();

    // 3. Determinante da matriz A
    double d = A.det();
    println(f"Determinante de A: {d}");
}

6.3.2 Álgebra Hipercomplexa 4D e Redes Neurais com GhostMatrix

O recurso GhostMatrix expande o domínio matricial para os números hipercomplexos G = x + y\cdot i + p\cdot g + \theta^2, integrando portas quânticas, funções de ativação de redes neurais e visão computacional:

  • Elementos Hipercomplexos 4D: Cada elemento da matriz armazena as quatro componentes ortogonais (real, imaginária, gradiente fantasma e incerteza Grassmanniana).
  • Transposição Matricial: O método G.transpose() permuta linhas e colunas preservando a assinatura quântica dos coeficientes.
  • Funções de Ativação Vetorizadas de IA: Suporte direto a ativações não lineares sobre a matriz inteira via métodos G.relu(), G.sigmoid(), G.tanh(), G.leaky_relu(), G.gelu() e G.softmax().
  • Visão Computacional: Métodos integrados para pooling 2D (G.max_pool2d(size, stride) e G.avg_pool2d(size, stride)) e convoluções aceleradas.
  • Persistência de Dados e Checkpoints: Leitura e escrita de datasets e pesos neurais via G.loadCSV("dados.csv"), G.save("pesos.bin") e G.load("pesos.bin").
exemplos/ghost_matrix.gGhostLang Source
// Álgebra Hipercomplexa G e Ativações de IA: GhostMatrix
function void main() {
    // 1. Instanciação com o construtor GhostMatrix
    GhostMatrix G(2, 2);

    // 2. Definindo elementos hipercomplexos 4D (x, y, p, theta2)
    ghost g1 = ghost(2.0, 1.0, 0.5, 0.0);
    ghost g2 = ghost(-3.0, 0.0, 1.2, 0.0);
    ghost g3 = ghost(1.5, -0.5, 0.0, 0.0);
    ghost g4 = ghost(4.0, 2.0, -1.0, 0.0);

    G.set(0, 0, g1);
    G.set(0, 1, g2);
    G.set(1, 0, g3);
    G.set(1, 1, g4);

    println("Matriz Hipercomplexa GhostMatrix G:");
    G.show();

    // 3. Transposição da matriz
    GhostMatrix G_t = G.transpose();
    println("Matriz Transposta G^T:");
    G_t.show();

    // 4. Multiplicação por escalar com propagação de incerteza
    GhostMatrix G_dobro = G * 2.0;
    println("Matriz G multiplicada pelo escalar 2.0:");
    G_dobro.show();

    // 5. Função de ativação não-linear ReLU para camadas de IA
    GhostMatrix G_relu = G.relu();
    println("Matriz apos ativacao ReLU:");
    G_relu.show();
}

import "libs/tensor.g";

function void main() {

7.1 O Tipo Nativo qreg e o Modelo Statevector

No GhostLang, o registrador quântico qreg representa um estado quântico puro de N qubits:

|ψ⟩ = ∑ αᵢ |i⟩,    com ∑ |αᵢ|² = 1.0,    αᵢ ∈ ℂ

A simulação statevector opera diretamente em memória contígua em C++ com precisão dupla. A partir de 13 qubits, a aceleração OpenMP paraleliza automaticamente os laços de produto tensorial, permitindo simular com velocidade até 28 qubits (268 milhões de amplitudes complexas).

🔬 Convenção Fundamental de Kets no GhostLang
O qubit 0 é sempre o bit menos significativo (à direita). Um estado com q₀ = 1 e q₁ = 0 é escrito como |01⟩. Da mesma forma, em strings de observáveis de Pauli como "XZ", o operador X atua sobre o qubit 1 e o operador Z sobre o qubit 0.

7.2 O Circuito de Bell: Entrelaçamento Quântico Básico

function void main() {

}

7.4 Algoritmo de Busca Quântica de Grover

O GhostLang possui suporte nativo para primitivas de oráculo quântico (phase_flip) e o operador de difusão de Grover (diffuser()), permitindo encontrar um elemento em uma base desordenada de N = 2ⁿ estados com complexidade 𝒪(√N):

exemplos/grover.gGhostLang Source
import "libs/quantum.g";

function void main() {
    int n = 3;               // 3 qubits -> 8 estados possíveis (0 a 7)
    int alvo_secreto = 6;    // Queremos localizar o número 6 (|110>)

    qreg q(n);
    q.h_all();               // Superposição uniforme sobre os 8 estados

    // Número ótimo de iterações: aproximadamente (pi / 4) * sqrt(8) ≈ 2
    for (int passo = 1; passo <= 2; passo = passo + 1) {
        q.phase_flip(alvo_secreto); // Oráculo: inverte a fase do estado procurado
        q.diffuser();              // Difusor de Grover: amplifica a amplitude em torno da média
    }

    println(f"Probabilidade de medir o alvo {alvo_secreto}: {q.prob_state(alvo_secreto) * 100}%");
    println("Histograma de 500 medições:");
    println(q.histogram(500));
}

Treinamento com otimizadores reais. rede => optimize(X, Y, epochs=N, lr=T, opt="...") treina a rede por retropropagação. Os otimizadores são estes:

function main() {
    // XOR: uma amostra por coluna (2 entradas, 4 amostras)
    gate X(2, 4);
    gate Y(1, 4);
    X(0, 1) = 0.0; X(1, 1) = 1.0; Y(0, 1) = 1.0;
    X(0, 2) = 1.0; X(1, 2) = 0.0; Y(0, 2) = 1.0;
    X(0, 3) = 1.0; X(1, 3) = 1.0;

    gate W2(1, 6);                 // 6 ocultos -> 1 saida
    for (int r = 0; r < 6; r++) { for (int c = 0; c < 2; c++) { W1(r, c) = ((r * 7 + c * 3) % 11) / 10.0 - 0.5; } }
    for (int c = 0; c < 6; c++) { W2(0, c) = ((c * 5) % 7) / 7.0 - 0.4; }
    network rede = W1 >> W2;

    rede => optimize(X, Y, epochs=800, lr=0.02, opt="adam");   // adam, sgd, momentum, rmsprop ou gd
    print("erro: ", rede.loss(X, Y), " acuracia: ", rede.accuracy(X, Y));
    print("xor(1,0) = ", rede.classify(1.0, 0.0));     // 1
    show(rede);   // network rede (classica): 2 -> [densa 6x2] -> [densa 1x6] -> 1 saida(s); 25 parametros treinaveis
}

8.3 Diferenciação Automática Dinâmica: Autograd Reverso

O módulo libs/autograd.g implementa um motor de Reverse-Mode Automatic Differentiation de alta performance:

exemplos/autograd.gGhostLang Source
import "libs/autograd.g" as ag;

function void main() {
    // W (2x2) rastreia gradiente; X (1x2) e o alvo, não
    var W = ag.tensor_create(2, 2, true, 0.5);
    var X = ag.tensor_create(1, 2, false, 2.0);
    var alvo = ag.tensor_create(1, 2, false, 1.0);

    var Y = ag.tensor_matmul(X, W);           // Y = X . W  (grafo dinâmico)
    var perda = ag.tensor_mse(Y, alvo);       // erro quadrático médio
    println(f"Y = [{ag.tensor_get(Y, 0, 0)}, {ag.tensor_get(Y, 0, 1)}]  perda = {ag.tensor_get(perda, 0, 0)}");

    ag.tensor_backward(perda);                // retropropagação reversa
    println(f"dPerda/dW[0,0] = {ag.tensor_grad(W, 0, 0)}");

    ag.tensor_step(W, 0.1);                   // W = W - 0.1 * gradiente
    println(f"W[0,0] depois do passo: {ag.tensor_get(W, 0, 0)}");
}

9.1 A Regra de Parameter-Shift: Derivadas Exatas de Circuitos

Diferente do cálculo numérico comum por diferenças finitas que sofre com instabilidades numéricas, circuitos quânticos variacionais admitem gradientes analíticos exatos através da Regra de Parameter-Shift:

∂⟨O⟩ / ∂θ = ( ⟨O⟩_(θ + π/2) - ⟨O⟩_(θ - π/2) ) / 2

O GhostLang calcula esses deslocamentos de fase diretamente no runtime C++ em src/GhostQML.cpp com precisão superior a 10⁻⁶, permitindo treinar portas unitárias parametrizadas (Rx, Ry, Rz) com o otimizador Adam ou SGD com a mesma fluidez de uma rede neural clássica.

9.2 Redes Híbridas com GhostQLayer: W1 >> Q >> W2

Uma das funcionalidades mais poderosas do GhostLang é a capacidade de inserir uma camada de processamento quântico diretamente entre camadas densas clássicas:

exemplos/rede_hibrida.gGhostLang Source
function void main() {
    // Dados: 64 pontos do quadrado [-1, 1]^2, uma amostra por coluna; classe 1 dentro do círculo
    gate X(2, 64);
    gate Y(1, 64);
    for (int i = 0; i < 8; i++) {
        for (int j = 0; j < 8; j++) {
            int k = i * 8 + j;
            double a = -1.0 + 2.0 * i / 7.0;
            double b = -1.0 + 2.0 * j / 7.0;
            X(0, k) = a;
            X(1, k) = b;
            Y(0, k) = a * a + b * b < 0.45 ? 1.0 : 0.0;
        }
    }

    gate W1(2, 2);       // densa clássica: 2 -> 2
    qlayer Q(2, 2);      // quântica: 2 qubits, 2 camadas treináveis
    gate W2(1, 2);       // densa clássica: 2 -> 1
    Q.seed(3);
    network rede_hibrida = W1 >> Q >> W2;

    println(f"Antes:  acuracia {rede_hibrida.accuracy(X, Y) * 100.0}%");
    rede_hibrida => optimize(X, Y, epochs=150, lr=0.05, opt="adam");

}

  • app.websocket_broadcast(rota, f): entrega a resposta a todos os conectados na rota.

No programa, o cliente usa ws_connect, ws_send, ws_recv(id, timeout_ms) e ws_close. No navegador, new WebSocket("ws://localhost:8080/sala") conversa com a mesma rota. Ainda não há wss:// (TLS).

exemplos/chat_websocket.gGhostLang Source
function string sala(string msg) { return "[sala] " + msg; }
function string eco(string msg) { return "eco: " + msg; }

function main() {
    server app = 8080;
    app.websocket("/eco", eco);                // responde so a quem mandou
    app.websocket_broadcast("/sala", sala);    // responde a todos da rota (chat)
    spawn {
        for (int i = 0; i < 100; i++) { app.listen_step(50); }
    }
    sleep(200);

    int b = ws_connect("ws://127.0.0.1:8080/sala");
    int c = ws_connect("ws://127.0.0.1:8080/sala");
    sleep(100);
    ws_send(b, "bia entrou");
    print(ws_recv(c, 3000));   // [sala] bia entrou
    ws_close(b);
    ws_close(c);
}

import "libs/quantum.g";

function void main() {
    qreg q(3); // q0: estado de Alice, q1-q2: par entrelaçado EPR

    // 1. Alice prepara seu qubit secreto com rotação
    q.ry(0, 3.14159265 / 3.0);

    // 2. Cria par EPR entre Bob (q2) e Alice (q1)
    q.h(1);
    q.cx(1, 2);

    // 3. Alice mede em base de Bell
    q.cx(0, 1);
    q.h(0);
    int m0 = q.measure(0);
    int m1 = q.measure(1);

    // 4. Bob aplica correções unitárias clássicas
    if (m1 == 1) { q.x(2); }
    if (m0 == 1) { q.z(2); }

    println("Teletransporte concluído com sucesso! Estado reconstruído em Bob (q2):");
    q.show();
}
