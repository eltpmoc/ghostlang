Assistente: No código deste projeto, um Número G é representado por (x + i y) + p theta, com o parâmetro theta2. x é a parte real, y a imaginária e p a fantasma. A implementação usa regras próprias; há diferenças documentadas em relação à descrição 4D do manual.
Exemplo:
function void main() {
    ghost a = GhostNumberG(1.0, 2.0, 3.0);
    ghost b = GhostNumberG(4.0, 5.0, 6.0);
    ghost soma = a + b;
    ghost produto = a * b;
    print("Soma: " + soma.x + ", " + soma.y + ", " + soma.p);
    print("Produto: " + produto.x + ", " + produto.y + ", " + produto.p);
}
Os construtores usam literais decimais explícitos. O exemplo lê as componentes .x, .y e .p para mostrar o cálculo sem depender dos sufixos algébricos antigos.

function void main() {
    pragma auto;
    state entrada = [1.0, 2.0];
    gate pesos(2, 2);
    pesos(0, 0) = GhostNumberG(1.0);
    pesos(0, 1) = GhostNumberG(0.0);
    pesos(1, 0) = GhostNumberG(0.0);
    pesos(1, 1) = GhostNumberG(2.0);
    state saida = pesos * entrada;

    print(saida(1, 0).x);
}

    print(saida(1, 0).x);
}
A primeira linha calcula 1*1 + 0*2 = 1. A segunda calcula 0*1 + 2*2 = 4. O modo auto pode manter esse produto pequeno na CPU.

Assistente: O padrão é GHOST_DEVICE=auto. O runtime testa CUDA e usa a GPU disponível; sem CUDA funcional, usa CPU. Você pode chamar use_device("auto") antes de preparar ou carregar o modelo. device_info informa a seleção.
Exemplo:
function void main() {
    pragma auto;
    print(device_info());
    textmodel ia = text_model(64, 32, 192, 32, 4096, 42);
    ia.self_test();
}
Troque pragma auto por pragma cpu para forçar CPU ou por pragma gpu para exigir CUDA.
