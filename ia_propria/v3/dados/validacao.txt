Usuário: Para que serve GhostLang?
Assistente: GhostLang é a linguagem deste projeto. Seu compilador transforma arquivos .g em C++ e gera um executável. Ela oferece tipos e operações para matrizes, redes neurais e Números G.

Usuário: Como gerar um executável GhostLang?
Assistente: Na raiz do projeto, use build_native/ghost programa.g -o programa. Depois execute ./programa. O compilador nativo liga automaticamente a biblioteca ghost_runtime.

Usuário: A V3 usa realmente GhostLang?
Assistente: Sim. A V3 declara seu textmodel e controla treino e execução em GhostLang. O compilador traduz o programa para C++; o runtime nativo implementa os cálculos em C++ e CUDA. Isso não significa que os kernels CUDA sejam escritos em sintaxe GhostLang.

Usuário: Qual tipo nativo cria o modelo de linguagem?
Assistente: textmodel é o tipo nativo para um modelo de linguagem treinável localmente. Exemplo: textmodel ia = text_model(64, 32, 192, 32, 4096, 42); Os argumentos são contexto, embedding, camada oculta, lote, limite de vocabulário e semente.

Usuário: Como funciona a rede de texto da V3?
Assistente: A V3 usa embeddings de palavras, uma janela fixa de contexto, camada oculta tanh e saída softmax. Treina com entropia cruzada e AdamW. É uma rede pequena, sem atenção Transformer, e sua capacidade de generalização é limitada.

Usuário: Como ajustar os pesos da IA em GhostLang?
Assistente: Declare o textmodel, chame prepare com arquivos de treino e validação, execute epoch com uma taxa de aprendizado, avalie com validate e grave com save. O script V3 oferece o comando treinar e preserva o melhor checkpoint de validação.

Usuário: Como retomar um treinamento?
Assistente: save grava pesos, momentos do AdamW, vocabulário, arquitetura, épocas e estado aleatório. load restaura o modelo. Para retomar com os textos, passe o checkpoint como terceiro argumento de prepare. O comando continuar faz isso na V3.

Usuário: A IA detecta a RTX automaticamente?
Assistente: O padrão é GHOST_DEVICE=auto. O runtime testa CUDA e usa a GPU disponível; sem CUDA funcional, usa CPU. Você pode chamar use_device("auto") antes de preparar ou carregar o modelo. device_info informa a seleção.

Usuário: Como escolher somente o processador?
Assistente: Use bash scripts/ia_v3.sh --device cpu chat, dentro de ia_propria. Em GhostLang, use use_device("cpu") antes de prepare ou load. A versão CPU também pode ser compilada com GHOST_CUDA=OFF.

Usuário: Como usar pragma gpu?
Assistente: Use bash scripts/ia_v3.sh --device cuda chat. Em GhostLang, use pragma gpu ou use_device("cuda") antes de preparar o modelo. Esse modo exige CUDA funcional e informa erro se ela não estiver disponível.

Usuário: Qual placa deste computador roda o backend CUDA?
Assistente: Este backend procura dispositivos pelo runtime CUDA. A RTX NVIDIA é a placa usada neste projeto. Não foi implementado um backend para a Intel UHD; a alternativa disponível aqui é CPU.

Usuário: O que a GPU acelera nesta versão?
Assistente: O textmodel executa passagem direta, gradientes e atualização AdamW na GPU. Produtos de GhostMatrix também têm kernel CUDA para x, y e p. Tokenização e interface ficam na CPU. Isso não torna automaticamente todos os recursos da linguagem operações de GPU.

Usuário: Para que serve o tipo state?
Assistente: state representa um vetor coluna de valores. Por exemplo: state entrada = [1.0, 0.0]; Ele pode ser usado como entrada de operações matriciais e redes neurais.

Usuário: Para que serve o tipo gate?
Assistente: gate representa uma matriz. Por exemplo: gate camada(3, 2); cria três linhas e duas colunas. A sintaxe também permite portas predefinidas como hadamard.

Usuário: Como conectar camadas em GhostLang?
Assistente: network conecta matrizes de pesos com o operador >>. Exemplo: network rede = camada1 >> camada2; É um recurso diferente de textmodel, que já reúne o modelo de linguagem e seu treinamento.

Usuário: Quais componentes a GPU multiplica nas matrizes?
Assistente: O kernel matricial reproduz as fórmulas atuais de GhostNumberG para x, y e p e devolve theta2 igual a zero, como o caminho CPU. O modo auto evita GPU em produtos pequenos para reduzir o custo de transferências.

Usuário: Qual é a teoria G definida no projeto?
Assistente: No código deste projeto, um Número G é representado por (x + i y) + p theta, com o parâmetro theta2. x é a parte real, y a imaginária e p a fantasma. A implementação usa regras próprias; há diferenças documentadas em relação à descrição 4D do manual.

Usuário: Como representar um Número Fantasma no código?
Assistente: Os componentes usados nas operações principais são x, y e p. O campo theta2 é um parâmetro adicional. Para criar um exemplo explícito, use ghost z = GhostNumberG(1.0, 2.0, 3.0, 0.0);

Usuário: Como funciona a soma no GhostNumberG?
Assistente: A soma adiciona x, y e p componente a componente. O resultado recebe theta2 igual a zero. Por exemplo, (1, 2, 3) + (4, 5, 6) produz (5, 7, 9) nessas três componentes.

Usuário: Como funciona a multiplicação em GhostNumberG?
Assistente: A regra implementada é x = x1*x2 - y1*y2; y = x1*y2 + y1*x2; p = x1*p2 + x2*p1. O resultado tem theta2 igual a zero. Termos envolvendo y e p não entram na parte fantasma dessa fórmula.

Usuário: O quadrado do fantasma puro é zero?
Assistente: Sim, no produto implementado, theta = (0, 0, 1) satisfaz theta*theta = (0, 0, 0). Essa afirmação descreve a regra executada no código, que retorna theta2 igual a zero.

Usuário: Existe um contraexemplo de associatividade em GhostNumberG?
Assistente: A implementação atual não é associativa em geral. Com i = (0, 1, 0) e theta = (0, 0, 1), temos (i*i)*theta = -theta, mas i*(i*theta) = 0. A integração CUDA preserva esse comportamento; não altera a teoria silenciosamente.

Usuário: Como a divisão trata um divisor fantasma puro?
Assistente: Se x e y do divisor forem próximos de zero, a divisão implementada devolve x = 0, y = 0 e transfere a magnitude complexa do numerador para p, ou preserva seu p quando essa magnitude é quase zero. Assim, 1.0 dividido por zero produz (0, 0, 1). É uma convenção do projeto, não a divisão usual.

Usuário: O que acontece com theta2 na soma e no produto?
Assistente: Soma, subtração e multiplicação retornam theta2 igual a zero na implementação atual. Outros métodos, como conjugate e set_theta2, podem preservá-lo ou alterá-lo. Portanto, o código atual não trata theta2 simplesmente como uma quarta coordenada aditiva.

Usuário: Qual fórmula usa x y p e theta2 na norma?
Assistente: norm_squared calcula x*x + y*y + p*p*theta2. Por exemplo, x = 3, y = 4, p = 2 e theta2 = 2 dão 33. real_norm_squared usa apenas x*x + y*y.

Usuário: Quais componentes mudam na conjugação?
Assistente: conjugate troca o sinal de y e preserva x, p e theta2. Portanto, o conjugado de (1, 2, 3, 4) é (1, -2, 3, 4).

Usuário: Qual é a ordem das componentes depois de rotate?
Assistente: rotate modifica o próprio objeto, fazendo x receber o antigo y, y receber o antigo p e p receber o antigo x. Por exemplo, (1, 2, 3) passa a (2, 3, 1).

Usuário: A teoria G já está consistente em todo o projeto?
Assistente: Há diferenças. O manual descreve a + bi + cg + d theta, enquanto as operações principais usam x, y e p e frequentemente zeram theta2. A V3 distingue documentação de comportamento executável. Consulte docs/NUMEROS_G_IMPLEMENTACAO.md para os exemplos verificados.

Usuário: A rede de texto usa a álgebra fantasma nos pesos?
Assistente: Não. O textmodel usa pesos reais float32 em CPU e CUDA. Ele recebe conteúdo sobre Números G nos textos de treinamento e na base documental. As matrizes GhostMatrix usam componentes G; isso é diferente de treinar o modelo de texto com pesos fantasmas.

Usuário: Como sei se a V3 consultou uma fonte?
Assistente: O modo fontes busca respostas revisadas na base local e mostra a origem. O modo neural gera tokens pelos pesos treinados e pode errar. No chat, use /neural ou /fontes. Uma boa resposta documental não mede a capacidade da rede.

Usuário: O chat treina o modelo em tempo real?
Assistente: Não. O chat não altera os pesos e não grava automaticamente suas mensagens. Para aprender novos textos, prepare um corpus e execute treinar ou continuar. A base de fontes também precisa ser revisada e recompilada para incluir novas respostas.

Usuário: Quando você foi treinada?
Assistente: Sou a IA V3 experimental deste projeto. Posso consultar a base local sobre GhostLang e Números G, com fontes, ou gerar texto com um modelo pequeno treinado localmente. Não tenho conhecimento geral amplo nem acesso automático à internet. As métricas e a data do treino ficam nos arquivos do checkpoint.

Usuário: Qual é o significado de algoritmo?
Assistente: Um algoritmo é uma sequência de instruções para realizar uma tarefa ou resolver um problema. Uma receita simples é um exemplo de passos organizados.

Usuário: Como você explica programação?
Assistente: Programar é escrever instruções para que um computador execute tarefas. O trabalho envolve entender o problema, criar uma solução e testar o resultado.

Usuário: Para que serve uma variável?
Assistente: Uma variável dá um nome a um valor usado pelo programa. Esse valor pode representar, por exemplo, uma quantidade, uma palavra ou um resultado.

Usuário: Como os testes ajudam na programação?
Assistente: Um teste verifica se o programa se comporta como esperado em determinada situação. Ele ajuda a encontrar erros e a conferir mudanças.

Usuário: Como começo a investigar uma falha no programa?
Assistente: Leia a mensagem de erro, identifique onde a falha ocorre e tente reproduzir o problema com um exemplo pequeno. Qual mensagem apareceu?

Usuário: Qual é a ideia de inteligência artificial?
Assistente: Inteligência artificial reúne métodos para realizar tarefas como reconhecer padrões e produzir previsões. Muitos modelos aprendem esses padrões a partir de exemplos.

Usuário: Como um modelo ajusta suas respostas?
Assistente: O modelo faz uma previsão, compara o resultado com um alvo e ajusta seus parâmetros para reduzir o erro. Esse processo é repetido com muitos exemplos.

Usuário: Como os textos ajudam uma IA a aprender?
Assistente: São os exemplos usados para ajustar o modelo. A qualidade, a diversidade e a organização desses dados influenciam o que ele consegue aprender.

Usuário: Como verificar se o modelo aprendeu além dos exemplos?
Assistente: A validação usa exemplos separados para avaliar o comportamento do modelo. Isso ajuda a perceber quando ele apenas memoriza os dados de treinamento.

Usuário: Como você explica RAM?
Assistente: A memória RAM guarda temporariamente dados que os programas estão usando. Seu conteúdo normalmente não é preservado quando o computador é desligado.

Usuário: Como uma GPU ajuda em cálculos?
Assistente: Uma GPU executa muitas operações em paralelo. Além de produzir imagens, ela pode acelerar cálculos quando o programa possui um backend compatível.

Usuário: Como proteger um arquivo contra perda?
Assistente: Uma cópia de segurança permite recuperar dados quando o original é perdido. Guarde cópias em locais separados e verifique se consegue restaurá-las.

Usuário: O que ajuda a proteger minhas senhas?
Assistente: Use uma senha longa e exclusiva para cada conta. Um gerenciador de senhas e a autenticação em dois fatores podem ajudar a proteger o acesso.

Usuário: Como avaliar se uma notícia está correta?

Usuário: Uma opinião é o mesmo que um fato?

Usuário: O que ajuda a entender o que alguém diz?
