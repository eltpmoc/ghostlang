# Conhecimento adquirido

O chat V3.4 salva aqui as referências públicas obtidas automaticamente.
Use /memoria para ver temas, fontes e datas dentro do chat.

Os arquivos .gkm são registros textuais do runtime GhostLang, não pesos neurais.
Evite editá-los durante o uso do programa. /limpar preserva esta base;
/internet off permite consultá-la sem novas conexões.

Veja ../MEMORIA_AUTONOMA.md para o formato, limites e política de atualização.
